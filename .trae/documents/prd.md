## 1. 产品概述

地质钻孔数据管理平台是面向地质勘查行业的专业数据管理与可视化工具，用于录入、管理、查询和可视化展示钻孔柱状图数据。平台通过自动生成钻孔柱状图和任意方向连孔剖面图，帮助地质工程师快速分析地层分布规律，提高工作效率。

- 解决地质钻孔数据管理分散、可视化困难、剖面绘制繁琐的问题
- 服务于地质勘查、矿产资源、工程勘察、水文地质等领域的专业人员
- 目标是成为行业内高效、专业的钻孔数据管理与可视化解决方案

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 地质工程师 | 账号登录 | 钻孔数据录入、编辑、查询、可视化、导出 |
| 项目管理员 | 账号登录 | 全部功能权限，用户管理，数据审核 |
| 访客 | 无需注册 | 数据浏览、查询，无编辑权限 |

### 2.2 功能模块

1. **钻孔录入模块**：钻孔基本信息录入、地层分层数据录入、岩性描述录入、采样信息管理
2. **柱状图渲染模块**：根据钻孔数据自动生成标准钻孔柱状图、支持自定义样式、交互式浏览
3. **剖面生成模块**：任意方向剖面线绘制、多钻孔连孔剖面图自动生成、地层插值算法
4. **空间查询模块**：基于地图的钻孔位置查询、区域查询、条件筛选、PostGIS空间分析
5. **数据导出模块**：钻孔数据导出为Excel、柱状图导出为图片、剖面图导出为CAD/PDF

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 首页 | 数据概览 | 项目统计、钻孔分布地图、快捷操作入口 |
| 钻孔列表 | 钻孔管理 | 钻孔数据列表、高级筛选、批量操作、导入导出 |
| 钻孔录入 | 钻孔录入 | 表单录入钻孔基本信息、地层分层数据、岩性描述 |
| 柱状图查看 | 柱状图渲染 | 单钻孔柱状图展示、缩放、标注、导出 |
| 剖面分析 | 剖面生成 | 地图上绘制剖面线、自动生成连孔剖面图、交互编辑 |
| 空间查询 | 空间查询 | 地图浏览、区域选择、空间条件查询、结果展示 |
| 数据导出 | 数据导出 | 多格式数据导出、批量导出、导出任务管理 |

## 4. 用户界面设计

### 4.1 设计风格

采用专业、简洁、高效的工业软件设计风格：

- **主色调**：深蓝色 (#165DFF) 代表专业和科技感，搭配大地色系辅助色
- **辅助色**：岩土棕 (#8B5A2B)、地层灰 (#6B7280)、植被绿 (#059669)、水文蓝 (#0EA5E9)
- **按钮风格**：方角微圆，3px圆角，线框+填充两种样式，悬停有微动画
- **字体**：标题使用"Noto Sans SC"，数据表格使用等宽字体"JetBrains Mono"
- **布局风格**：左侧导航栏+顶部工具栏+主内容区三栏布局，支持多标签页
- **图标风格**：使用Lucide图标库，线性风格，统一24px尺寸

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|----------|--------|
| 首页 | 数据概览 | 统计卡片、地图容器、快捷操作区、最近钻孔列表 |
| 钻孔列表 | 钻孔管理 | 高级筛选面板、数据表格、分页器、批量操作工具栏 |
| 钻孔录入 | 钻孔录入 | 分步表单、地层分层表格、岩性字典选择器、实时预览 |
| 柱状图查看 | 柱状图渲染 | SVG绘图区、缩放控制、图例面板、标注工具栏 |
| 剖面分析 | 剖面生成 | 地图剖面线绘制、剖面图绘图区、地层插值参数设置 |
| 空间查询 | 空间查询 | 地图控件、查询条件面板、结果列表、空间分析工具 |
| 数据导出 | 数据导出 | 格式选择器、参数配置、导出进度、历史记录 |

### 4.3 响应式设计

- **桌面优先**：针对1920×1080及以上分辨率优化，支持多窗口布局
- **平板适配**：≥768px，导航栏可折叠，数据表格支持水平滚动
- **移动适配**：<768px，底部导航栏，简化操作流程，重点展示数据浏览功能
- **触摸优化**：可交互元素最小44×44px，支持手势缩放地图和图表

### 4.4 地图场景设计

钻孔分布地图和剖面图绘制场景：

- **底图**：使用天地图或高德地图卫星影像+路网叠加，支持透明度调节
- **钻孔符号**：圆形钻孔标记，按深度分级显示颜色，悬停显示基本信息
- **剖面线**：虚线显示，可拖拽调整端点，沿线高亮显示经过的钻孔
- **交互**：支持滚轮缩放、拖拽平移、框选查询、点击查看详情
- **性能**：使用Canvas渲染大量钻孔点，支持万级数据量流畅展示
